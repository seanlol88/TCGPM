Connect Google Drive

To enable Google Drive backups, you need to set up a Google Cloud project first:

  1. Go to Google Cloud Console and create a new project.
  2. Enable the Google Drive API for your project.
  3. Create OAuth 2.0 credentials (Desktop app type).
  4. Download the credentials JSON file.
  5. Rename it to drive_credentials.json and place it in the project root folder (where main.py is located).
  6. Set the Authorized redirect URI to: http://localhost:8000/backups/google-drive/callback

⚠️ After placing the file, restart the application and click "Connect Now" to authorize access.
